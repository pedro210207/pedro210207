## 🚀 Projetos em Destaque

### 🎮 [Mercado Gamer Analytics - Data Engineering & BI](https://github.com/pedro210207/mercado_gamer_analytics)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-yellow?style=for-the-badge)
<div align="justify">
Plataforma analítica End-to-End desenvolvida para mapear tendências, lucratividade e relevância de publishers no mercado global de games.
<ul>
  <li><strong>ETL:</strong> Extração automatizada de dados reais via APIs com <code>Requests</code> e engenharia de atributos/limpeza de dados utilizando <code>Pandas</code>.</li>
  <li><strong>Modelagem de Dados:</strong> Estruturação de banco de dados relacional em ambiente <code>MySQL</code> utilizando o modelo multidimensional Star Schema (Tabelas Fato e Dimensão) e otimização através de Views analíticas.</li>
  <li><strong>BI & Visualização:</strong> Construção de um Dashboard executivo de alta fidelidade no <code>Power BI</code> conectado diretamente ao MySQL, utilizando cálculos complexos em <code>DAX</code> para responder a dores de negócio reais.</li>
</ul>
</div>

### 🛒 [Sistema de Ponto de Venda (PDV) - Analytics](https://github.com/pedro210207/ponto_de_venda)
<div align="justify">
Aplicação robusta voltada para a modelagem de banco de dados e inteligência comercial.
<ul>
  <li><strong>Geração de Dados:</strong> Desenvolvimento de scripts em <code>Python</code> para popular tabelas relacionais com mais de 500 registros realistas, garantindo cenários ideais para simulações e análise de performance.</li>
  <li><strong>Análise de Negócio:</strong> Aplicação de rotinas de ETL com <code>Pandas</code> no <code>MySQL</code> para levantamento de indicadores vitais de performance comercial (KPIs de faturamento, Ticket Médio, curvas de sazonalidade e Curva ABC de produtos).</li>
  <li><strong>Visualização Gerencial:</strong> Criação de painel interativo no <code>Power BI</code> integrado ao banco de dados para monitoramento em tempo real do fluxo de vendas.</li>
</ul>
</div>

### 📈 [Análise de Performance Gamer](https://github.com/pedro210207/analise_performance_gamer)
<div align="justify">
Estudo analítico focado em cruzamento de dados comportamentais e identificação de padrões de desempenho.
<ul>
  <li><strong>Estruturação:</strong> Modelagem relacional construída em <code>MySQL</code> para capturar sessões de jogo e variáveis externas.</li>
  <li><strong>Análise Estatística:</strong> Desenvolvimento de lógica em <code>Python (Pandas)</code> para cruzar dados de performance com fatores fisiológicos (horas de sono, foco, hardware), transformando métricas brutas em relatórios preditivos de riscos e gargalos de performance.</li>
</ul>
