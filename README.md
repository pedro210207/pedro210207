## 🚀 Projetos em Destaque

### 🎮 [Mercado Gamer Analytics - Data Engineering & BI](https://github.com/pedro210207/mercado_gamer_analytics)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-yellow?style=for-the-badge)
Plataforma analítica *End-to-End* para mapeamento de tendências e lucratividade no mercado de games.
* **ETL:** Extração via APIs com `Requests` e limpeza de dados com `Pandas`.
* **Modelagem:** Estruturação em *Star Schema* (Fatos e Dimensões) no MySQL.
* **BI:** Dashboard executivo no Power BI utilizando DAX para suporte à decisão estratégica.

### 🛒 [Sistema de Ponto de Venda (PDV) - Analytics](https://github.com/pedro210207/ponto_de_venda)
Aplicação voltada para engenharia de dados e análise de performance comercial.
* **Automação:** Script Python para geração de massa de dados (500+ registros realistas).
* **Análise:** Rotinas de ETL para cálculo de KPIs (Ticket Médio, Sazonalidade, Pareto de Produtos).
* **Visualização:** Dashboards gerenciais conectados via Live Connection ao banco MySQL.

### 📈 [Análise de Performance Gamer](https://github.com/pedro210207/analise_performance_gamer)
Estudo focado em correlação de dados e identificação de perfis de risco.
* **Engenharia:** Modelagem relacional para registro de sessões de jogos.
* **Data Science:** Algoritmos em Python/Pandas para correlacionar fatores comportamentais (foco/sono) com performance in-game.
